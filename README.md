### KedataForm Studio

Aplikasi pembuat formulir dengan backend Express dan MySQL, login Google OAuth 2.0, serta frontend React 19, Vite, dan Tailwind. Seluruh data form, respons, dan pengguna tersimpan di MySQL.

React, TypeScript, Express, MySQL

[Repo](https://github.com/aiininratnadwitanti/kedataform) · [Demo](https://kedataform.vercel.app)

### Kost Finder

Prototype UI/UX aplikasi pencarian kost: alur pencarian, filter, dan tampilan detail dengan data contoh. Fokus pada desain antarmuka, tanpa backend.

React, TypeScript, UI/UX

[Repo](https://github.com/aiininratnadwitanti/kost-finder)

### PatunganBeres

Aplikasi split bill dan iuran bersama: scan struk dengan AI, hitung pajak dan service charge, lalu bagikan struk digital ke tiap peserta.

Laravel, PHP, MySQL, Gemini AI

[Repo](https://github.com/aiininratnadwitanti/patunganberes)
